# CARVIS CORE C – Beta 1.00
Kostenlose Web-App (PWA), keine echte KI, lokale Demo-Engine (als "SIMULIERT" gekennzeichnet).

## Lokal testen
`python -m http.server 8000` im Ordner, dann http://localhost:8000

## Kostenlos veröffentlichen (GitHub Pages)
1. github.com → New repository → Name `ccc` → Public → Create.
2. "uploading an existing file" → alle Dateien dieses Ordners hochladen → Commit.
3. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Min: https://DEINNAME.github.io/ccc/

## Installieren
- iPhone: Safari → Teilen → "Zum Home-Bildschirm".
- Windows: Chrome/Edge → Installieren-Symbol in der Adressleiste.

## Grenzen
Kein Hey-C-Wake-Word (Mikrofontaste), keine Ultimate-Funktionen, keine echte KI-Anbindung.
